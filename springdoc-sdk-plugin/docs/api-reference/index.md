# API Reference

## Overview
Example API for documentation generation
Version: 1.0.0

## Base URL
- `https://api.example.com` - Production server

## Available Endpoints

### /users
#### GET
Get all users
Returns a list of all users

#### POST
Create a new user
Creates a new user with the provided data

### /users/{userId}
#### GET
Get user by ID
Returns a single user by ID

### ApiKeyAuth
