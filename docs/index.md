# SpringDoc Demo Documentation

Welcome to the SpringDoc Demo documentation. This project demonstrates how to generate and maintain API documentation using SpringDoc and OpenAPI.

## Features

- Auto-generated API documentation with Swagger UI
- Beautiful documentation using MkDocs
- Automatic client SDK generation
- Comprehensive test coverage

- [Getting Started](getting-started/index.md)

## API Documentation

The API documentation is available in multiple formats:

- [Swagger UI](http://localhost:8080/swagger-ui.html)
- [OpenAPI YAML](http://localhost:8080/v3/api-docs.yaml)
