## Community Guidelines

### Code of Conduct

We maintain a friendly, respectful environment for all community members. Please review our [Code of Conduct](https://example.com/code-of-conduct) which covers:
- Expected behavior
- Unacceptable behavior
- Reporting procedures
- Enforcement policies

### Best Practices

1. **When Asking Questions**
   - Search existing discussions first
   - Provide relevant context
   - Include code examples when applicable
   - Be specific about your problem

2. **When Helping Others**
   - Be patient and respectful
   - Ask for clarification if needed
   - Provide explanations, not just solutions
   - Share relevant documentation links
